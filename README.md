# About this website

This is a personal website customized by me without relying on any templates or site building tools. It can easily centralize the management of many markdown files, and realize the basic functions of academic homepage, personal blog and so on. The core files of the whole project library are only index.html, main.css and main.js, and the future expandability on this basis is very strong.
In addition, I also added some small games and easter Eggs to increase the fun of the site! 😄
