# About this site

---

This is a very clean personal website that does not rely on any templates or site building tools. It utilizes dynamic rendering to assemble many markdown files to realize the basic functions of academic homepage, personal blog and so on. The core files are only index.html, main.css and main.js, which have high expandability in the future.
This project is my first project as a newbie to build a website, DeepSeek and ChatGPT taught me a lot in these three days.
