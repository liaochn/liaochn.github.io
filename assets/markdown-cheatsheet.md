# Markdown 语法速查表

### 目录

1.标题：# 到 ######

2.段落：空一行分隔

3.强调：* 或 **

4.列表：- 或 1.

5.代码：` 或

6.链接：[文本](URL)

•7图片：![替代文本](图片URL)

8.引用：>

9.表格：| 和 -

10.分隔线：---

11.任务列表：- [ ] 或 - [x]

12.内嵌 HTML：直接写 HTML 标签

13.转义字符：\

14.注释：<!-- -->

15.脚注：[^标签]

16.内嵌内容：通过 HTML 实现

________________________________________
# 1. 标题
使用 # 表示标题，# 的数量代表标题的级别。

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
________________________________________
# 2. 段落
段落之间需要空一行。

这是第一段。

这是第二段。
________________________________________
# 3. 强调
使用 * 或 _ 表示斜体，** 或 __ 表示加粗。

*斜体* 或 _斜体_
**加粗** 或 __加粗__
________________________________________
# 4. 列表
无序列表
使用 -、* 或 + 表示无序列表。

- 列表项 1
- 列表项 2
  - 子列表项 1
  - 子列表项 2
有序列表
使用数字加点表示有序列表。

1. 列表项 1
2. 列表项 2
   1. 子列表项 1
   2. 子列表项 2
________________________________________
# 5. 代码
行内代码
使用反引号 ` 表示行内代码。

这是 `行内代码` 的示例。
代码块
使用三个反引号 表示代码块。

```javascript
function hello() {
  console.log('Hello, world!');
}
```
________________________________________
# 6. 链接
使用 [文本](URL) 表示链接。

[百度](https://www.baidu.com)
________________________________________
# 7. 图片
使用 ![替代文本](图片URL) 表示图片。

![Markdown Logo](https://markdown-here.com/img/icon256.png)
________________________________________
# 8. 引用
使用 > 表示引用。

> 这是一个引用。
>
> 这是引用的第二行。
________________________________________
# 9. 表格
使用 | 和 - 表示表格。

| 表头 1 | 表头 2 |
| ------ | ------ |
| 单元格 1 | 单元格 2 |
| 单元格 3 | 单元格 4 |
________________________________________
# 10. 分隔线
使用 --- 或 *** 表示分隔线。

---
________________________________________
# 11. 任务列表
使用 - [ ] 表示未完成任务，- [x] 表示已完成任务。

- [x] 任务 1
- [ ] 任务 2
________________________________________
# 12. 内嵌 HTML
如果 Markdown 无法满足需求，可以直接使用 HTML。

<p style="color: red;">这是红色的文字。</p>

________________________________________

# 13. 转义字符
如果需要显示特殊字符（如 #、* 等），可以使用反斜杠 \ 进行转义。

这是 \*不是斜体\* 的示例。
________________________________________
# 14. 注释
Markdown 本身不支持注释，但可以通过 HTML 注释实现。

<!-- 这是一个注释 -->
________________________________________
# 15. 脚注
使用 [^标签] 表示脚注。

这是一个脚注的示例[^example].

[^example]: 这是脚注的内容。
________________________________________
# 16. 内嵌内容
## 视频
Markdown 不支持直接嵌入视频，但可以通过 HTML 实现。
```
<iframe width="560" height="315" src="https://www.youtube.com/embed/视频ID" frameborder="0" allowfullscreen></iframe>
```

## 音频
同样，音频可以通过 HTML 嵌入。
````
<audio controls>
  <source src="音频文件.mp3" type="audio/mpeg">
</audio>
````
